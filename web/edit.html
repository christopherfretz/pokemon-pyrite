Put me in…

Each entry is a real spawn point in the game data, so you land standing on that map’s arrival tile. Indoor spawns put you inside.

The game only loads a map’s NPCs when you walk into it, so right after a move the new map is empty of people. Step out and back in (or through a door) and everyone appears. Nothing else is affected.

Party

PIKACHU caveat: the follower needs the starter PIKACHU in the party. Removing it (or replacing slot 1 with something else) leaves you with no follower until you get it back.

Changing a slot’s species or level recalculates its stats and sets EXP to the minimum for that level, using the ROM’s own base stats and growth curve. Stat EXP is left alone.

Bag

HMs cannot be tossed in-game, so an HM you add here stays for good. TMs and HMs share one list because the cartridge stores them that way.

Event flags

Flags are the game’s own bookkeeping. Turning one on out of order can leave an NPC or a scene in a state the script never expects — use the presets if you just want to be further along.

Presets & files

A preset replaces your whole save with a fixture from the test harness. Your current save is kept as the restore point.
